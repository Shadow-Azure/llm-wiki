# 飞书 aily

> 一句话：飞书 aily（"飞书智能伙伴创建平台"）是字节跳动飞书旗下的企业级智能体平台——用户可"零门槛创建与更新业务技能"，智能伙伴常驻对话列表、沉淀工作记忆；但"百余元 token 生成了价值 2 万元系统应用"的发布会案例实际出自同场发布的**飞书妙搭**（Miaoda），不是 aily 本体。

## 是什么 / 背景

- **官方定位**：「飞书智能伙伴创建平台」（飞书 aily）是"一款全新的企业级智能体平台，围绕着大语言模型（LLM）提供 **AI 技能编排、知识数据处理、效果调优和持续运营**能力，让用户可以高效的开发出专业的企业级智能应用，并一键发布到飞书、Web 等多个渠道"。https://www.feishu.cn/content/3d5z9ttt
- **产品矩阵背景**（2026-03-19 飞书发布会，新华网报道 http://www.news.cn/tech/20260319/e76a237bb21645b6a6f9ced193222cdd/c.html ）：
  - **飞书 aily（智能伙伴）**：用户点击即可在飞书内获得"智能伙伴"，以对话机器人形态常驻联系人列表，深度嵌入飞书工作流，"帮用户实时跟进工作动态、主动交付工作成果"；
  - **飞书妙搭**：用户"通过自然语言即可驱动 Agent 生成复杂的业务系统和智能体"；
  - **多维表格 AI 搭建**：自然语言描述需求即可生成数据表、仪表盘、问卷、权限配置乃至整套业务系统；
  - 另发布 OpenClaw 官方插件与一键部署等 Agent 友好能力（火山引擎、阶跃星辰、Kimi、扣子、MiniMax、智谱等已对接）。CEO 谢欣："我们希望在今年，让每个人都拥有自己的智能工作伙伴。"
- **平台能力构成**（官方页 https://www.feishu.cn/content/3d5z9ttt ）：数据源接入（飞书文档/多维表格/数据库，20+ 种数据源）、智能数据预处理（打标、切片）、Agent 智能规划与执行（调度上百个企业服务连接器）、可视化工作流编排、多渠道一键部署、开放 API（多轮对话、图片问答、技能调用、知识创建）。

## 机制：技能如何被创建与"进化"

- **技能创建**：新华网对 aily 智能伙伴的表述为——"不仅内置飞书内的办公技能，还支持**零门槛创建与更新各类安全可靠的业务技能**"。平台侧的技能开发范式是 **Workflow 技能编排**（在飞书智能伙伴应用创建平台创建 Workflow 技能、定义出入参，节点含 LLM、智能对话、OCR 等）。https://aily.feishu.cn/hc/1u7kleqg/897wr1b8 ；http://www.news.cn/tech/20260319/e76a237bb21645b6a6f9ced193222cdd/c.html
- **记忆与自动优化**：官方叙事称 aily 智能伙伴"能在真实工作中**沉淀记忆，自动学习优化**"（新华网同文）；aily 帮助中心的"专属工作伙伴"文档亦称"内置丰富官方技能库，用户可自定义安装技能，专属工作伙伴可以**自主发现、安装需要的技能**"（https://aily.feishu.cn/hc/1u7kleqg/jsmwydi4 ，该页为 JS 渲染，此句引自检索摘要，未能直接抓取原文核验）。
- **权限模型**：aily 与用户本人权限严格一致，"确保了操作可控与数据安全"（新华网）。
- **运维观测**：aily 运行分析提供"技能成功率"与"Token 用量"两大监控指标，用于稳定性与成本控制。https://www.feishu.cn/content/pgdfhrny
- **计费**：平台以"运行额度"计费（首次开通赠 20,000 运行额度）；飞书 AI 版按 token 消耗额度叠加计费（990 元/月、9,900 元/年、99,000 元/年，AI 额度 18 万起）。https://www.feishu.cn/content/1cnvbb55 ；https://www.feishu.cn/hc/zh-CN/articles/629644238181
