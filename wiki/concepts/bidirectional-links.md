# 双向链接与关系图谱

**一句话定义**：双向链接是"前向链接只存一份文本、由运行时反向索引使其可从两端遍历"的链接机制；关系图谱是这份链接索引的可视化投影。

> 本页由 query 回填（2026-08-23）。graph view 作为 wiki 体检工具的论断可溯源至 Karpathy 原文（raw）；Obsidian 具体语法与面板为产品事实（官方文档待剪藏）；分析性论断已标注"AI 推断，待来源验证"。

## 三层结构（祛魅版）

| 层 | 是什么 | 性质 |
|---|---|---|
| `[[链接]]` 文本 | 写进 .md 文件的单向链接 | 唯一被持久化的东西 |
| 反向索引（backlinks / metadata cache） | 打开库时扫描全库文件算出的"谁指向我" | 查询优化结构，可丢弃、可重建，删掉数据无损 |
| 关系图谱（graph view） | 链接集合的可视化 | 派生视图，关掉功能数据无损 |

关键澄清：**图谱不需要反向索引也能画**——边集合 = 全库前向链接的并集，每条边都在某个文件的文本里显式存在。反向索引对图谱的贡献只有节点**入度统计**（枢纽/孤儿的判断依据）。"双向"指的是**遍历能力**（从任一端都能走到另一端），不是把边存储成双向边；图上 A→B 仍是一条有向边，默认只是不显示箭头。

类比：学术论文的参考文献（前向，显式存储）与 SCI 引文索引（反向，Garfield 1955）——"谁引了我"从来不需要作者写进论文，索引负责反向查询。

## 语法（Obsidian 实现）

| 写法 | 效果 |
|---|---|
| `[[页面名]]` | 基本链接，`[[` 触发全库自动补全 |
| `[[页面名\|显示文字]]` | 别名链接 |
| `[[页面名#小节]]` / `[[页面名^块ID]]` | 小节级 / 块级引用 |
| `![[...]]` | 嵌入（transclusion），引用即包含 |
| frontmatter properties 内的链接 | 同样计入链接索引 |

接收端侧栏两个面板：

- **Linked mentions（链接提及）**：全库哪些 `[[]]` 指向本页——反向导航的发动机；
- **Unlinked mentions（未链接提及）**：正文未加双方括号的同名纯文本提及，可一键转链——"潜在连接探测器"。

## 两个关键机制

1. **断链合法（unresolved links）**：链接到尚不存在的页面是合法状态（灰色显示）→ 可以**先连接、后填充**，与传统"先建页再加超链"路径相反；
2. **多重上下文**：文件夹中一个笔记只有一个父目录；backlinks 使一个笔记同时活在任意多个语境里——每条入链就是一个语境。突破单父级树，这是"网状"的实质。

## 图谱用法

- **全局图**：全库星图；**局部图（local graph）**：当前笔记的邻域（深度 1-3 层可调），日常导航更实用；
- 颜色分组（按路径/标签/frontmatter 染色）、箭头开关、孤点过滤；
- 三种诊断信号（Karpathy 原文："graph view is the best way to see the shape of your wiki — what's connected to what, which pages are hubs, which are orphans"）：
  1. **孤岛**（无入链）→ 对应本库 lint 清单的"无入链孤儿页"检查
  2. **枢纽**（高入链）→ 知识网络的重心
  3. **断链**（灰色虚点）→ 埋了未兑现的链接，即待写页面

## 反向索引的作用清单

1. Backlinks 面板：即时"谁指向我"，免每次全库扫描；
2. Unlinked mentions 检测；
3. 图谱节点入度（枢纽可视化）；
4. **变化即时传播**：新页面写下 `[[B]]`，B 的 backlinks 立即更新，无需任何人在 B 侧登记——库是自我组织的。

## 与 LLM Wiki 模式的连接

第 4 条是该模式的微观基础：agent 写前向链接，反向那半张网由机器即时编织——[[wiki/concepts/wiki-vs-rag|编译式知识库 vs RAG]] 中"交叉引用已建好"在工具层靠的就是它，也是 [[wiki/concepts/llm-wiki|LLM Wiki]]"维护成本趋零"成立前提的机制支点。分工画面：agent 写 `[[]]` 是为图谱添边（输出物），人看图谱是观察 agent 的工作成果（观察窗）。

## 思想谱系

Bush **Memex**（1945，关联轨迹）→ Luhmann **Zettelkasten**（纸片编号互链）→ Ward Cunningham **WikiWikiWeb**（1995，wikilink 语法比 Obsidian 老 25 年）→ **Roam Research**（2020，把 backlinks 提为一等公民）→ **Obsidian**（做在本地纯文本上）。Obsidian 是集大成者而非发明者。

## 局限（AI 推断，待来源验证）

- 图谱只显示**显式链接**，不显示**语义相关**——未被 `[[]]` 连接但内容相关的笔记在图上毫无关系；Smart Connections 类 embedding 插件补的正是这个位（隐式连接探测）；
- 链接密度 ≠ 理解质量（"收藏家谬误"）——图谱反映**结构健康度**，不反映认知深度。
